ESCP website redesign

DEPLOY
1. Extract this ZIP.
2. Open the GitHub repository connected to your existing Vercel project.
3. Upload all HTML files, the assets folder and vercel.json to the repository root, replacing the previous index.html. Do not upload the ZIP itself.
4. Commit to the production branch. Your existing Git integration should trigger deployment.
5. In Vercel use Framework Preset Other, no build command and output directory . if configuration is needed.

CONTENT
Eight dedicated programme pages, subject imagery, intake calendar, available official videos/replays and an interactive funding guide. Geopolitics is forthcoming. Unconfirmed information is labelled.
Programme information is a snapshot checked 14 October 2026. It does not automatically sync with Google Drive. Edit the HTML pages to update content. Programme/media JSON files are reference data; editing them alone does not update the website.
Funding estimates are indicative. Confirm exact session eligibility, financial contribution and final amounts on Mon Compte Formation.
